# 분석 평가 기준

학생부종합전형의 일반적 평가요소를 5개 영역으로 정리. 각 영역은 0~100 점수와 근거 코멘트로 산출된다.
(`worker/analysis.ts`의 `scores[].dimension`과 일치시킨다.)

## 5개 평가 영역

### 1. 학업역량 (academic)
- 교과 성취와 세특에 드러난 개념 이해·지적 성장.
- 단순 등급이 아니라 "어떻게 공부했는가", 심화·확장 학습 흔적.

### 2. 전공적합성 (major-fit)
- 지원(희망) 계열과 활동·세특·독서의 연계 일관성.
- 관심 분야가 학년에 걸쳐 발전했는가.

### 3. 발전가능성 (growth)
- 시간 흐름에 따른 성장 곡선, 실패·보완 경험, 자기주도성.
- 주어진 환경에서 기회를 만들어낸 흔적.

### 4. 인성·공동체 (character)
- 협업, 배려, 책임, 봉사의 진정성. 행동특성및종합의견의 정성 평가.

### 5. 탐구역량 (inquiry)
- 호기심 → 질문 → 탐구 → 산출 → 후속활동으로 이어지는 연결성.
- 활동 간 "연결"이 핵심. 단발성 나열이 아니라 스토리.

## 점수 가이드 (정성 기준)

| 점수대 | 의미 |
|---|---|
| 90~100 | 해당 영역 근거가 풍부하고 깊이·연결성이 뛰어남 |
| 75~89 | 견고함. 한두 가지 보완 시 상위권 |
| 60~74 | 평이. 차별화 포인트 부족 |
| 40~59 | 근거 빈약. 구체적 활동·기록 보강 필요 |
| 0~39 | 해당 영역 기록이 거의 없음 |

## 추천 전공 산출 원칙

- 생기부에 드러난 **실제 관심·활동 근거**에서 도출(임의 추천 금지).
- 각 전공에 적합도(0~100)와 "왜 이 전공인지" 근거를 단다.
- 상위 3~5개. 안전/적정/도전을 섞기보다 **근거 강한 순**으로.

## 후속 탐구활동 제안 원칙

- 학생의 현재 활동에서 **자연스럽게 한 걸음 더** 나아가는 주제.
- 각 제안: 주제 / 왜 이게 너에게 맞는지 / 연계 전공.
- 거창한 대회보다 실행 가능한 탐구(소논문, 후속 실험, 심화 독서→발표 등) 우선.
