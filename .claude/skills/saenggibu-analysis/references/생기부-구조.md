# 학교생활기록부(생기부) 구조

분석 대상이 되는 생기부의 주요 항목. 학생이 붙여넣는 텍스트는 보통 이 항목들의 일부/전부다.
분석 엔진은 입력에 존재하는 항목만 다루고, 없는 항목은 만들어내지 않는다.

## 주요 항목

| 항목 | 코드상 section 값 예시 | 설명 | 분석 포인트 |
|---|---|---|---|
| 교과학습발달상황 / 세부능력 및 특기사항(세특) | `교과세특` | 과목별 교사 관찰 기록 | 전공 연계 깊이, 탐구·주도성, 개념 이해 |
| 창의적 체험활동 - 자율활동 | `자율활동` | 학급·학교 단위 활동 | 리더십, 공동체 기여 |
| 창의적 체험활동 - 동아리활동 | `동아리활동` | 동아리 | 관심사 일관성, 전공 적합성 |
| 창의적 체험활동 - 봉사활동 | `봉사활동` | 봉사 실적·소감 | 인성, 지속성, 진정성 |
| 창의적 체험활동 - 진로활동 | `진로활동` | 진로 탐색 | 진로 구체성, 탐구 연계 |
| 행동특성 및 종합의견 | `행동특성및종합의견` | 담임 종합 평가 | 인성, 성장, 학업태도 총평 |
| 독서활동상황 | `독서` | 읽은 책 목록/기록 | 지적 호기심, 전공 연계 독서 |
| 수상경력 | `수상경력` | 교내 수상 | 역량 근거(정량/정성) |
| 자격증 및 인증 | `자격증` | 취득 자격 | 직무·전공 연계 |
| 출결상황 | `출결` | 결석/지각 등 | 성실성(이상치만 언급) |

> 2024학년도 이후 대입에서 수상경력·독서활동·자율동아리 등 일부는 대학에 미반영될 수 있다.
> 분석 시 "대입 반영 여부"를 단정하지 말고, 학생의 역량 근거로만 활용한다.

## 평가 영역과의 매핑

생기부 항목 → 학생부종합전형 평가요소(아래 [분석-기준.md](분석-기준.md))로 연결한다.

- 학업역량 ← 교과세특, 수상경력
- 전공적합성 ← 동아리·진로활동, 전공연계 세특/독서
- 발전가능성 ← 시간에 따른 성장, 자기주도 탐구
- 인성·공동체 ← 봉사활동, 행동특성및종합의견, 자율활동
- 탐구역량 ← 세특·진로활동의 탐구 깊이, 후속활동 연결성
