# 생기부 AI · 사용자 매뉴얼

교사용 **AI 생기부 분석 + 학교 업무 지원** 웹 서비스 사용 안내입니다.
처음 사용하시는 분도 이 순서대로 따라 하시면 바로 활용할 수 있습니다.

- 서비스 주소: **https://sr-project.pages.dev**
- 권장 브라우저: Chrome, Edge (최신 버전)

---

## 1. 빠른 시작 (4단계)

1. **로그인** — 이메일로 회원가입·로그인하거나, 체험은 **‘관리자 테스트 로그인’** 버튼으로 바로 입장.
2. **학생 등록** — `생기부 분석 → 학생 관리`에서 학생 추가 (이름·학년·희망 전공).
3. **생기부 입력** — 학생을 열고 `생기부 추가` → 내용을 붙여넣기 하거나 **txt·PDF 파일 불러오기**.
4. **AI 분석** — `AI 분석` 클릭 → 강점·보완점·추천 전공·면접 질문 리포트 생성.

> 💡 화면 왼쪽 위 **❓(사용 안내)** 또는 메뉴의 **📖 사용 안내**를 누르면 앱 안에서도 같은 설명을 볼 수 있습니다.

---

## 2. 화면 구성

- **왼쪽 사이드바**: 기능 메뉴 (대시보드 · 생기부 분석 · 수업 자료 · 문서 작성 · 시스템 관리).
  - 메뉴 그룹의 ▾ 를 눌러 펼치고 접을 수 있습니다.
- **상단 바**: 알림, 계정(이메일·로그아웃).
- **가운데**: 선택한 기능 화면.

---

## 3. 기능별 사용법

### 📊 생기부 분석
1. **학생 관리**
   - `+ 새 학생 만들기`로 학생 등록 (이름은 필수, 학년·희망 전공은 선택).
   - 상단의 **⬇ CSV 내보내기 / ⬆ CSV 가져오기**로 명단을 엑셀로 주고받을 수 있습니다.
     (가져오기 형식: 첫 줄 `이름,학년,희망전공`, 다음 줄부터 학생 정보)
2. **생기부 작성·관리**
   - 학생을 클릭 → `+ 생기부 추가` → 제목 입력.
   - 본문에 세특·창의적 체험활동·행동특성 등을 **붙여넣기**, 또는 **📎 파일 불러오기**(txt·PDF)로 자동 입력.
   - 입력하는 동안 **글자수·byte 카운터**와 **기재 주의 표현 검사**(어학시험·대학명·교외 수상·사교육·부모 배경 등)가 실시간 표시됩니다.
   - **저장** 버튼으로 내용을 보관합니다.
3. **AI 분석 & 리포트**
   - **AI 분석** 클릭 → 종합 경쟁력 점수, 영역별 진단(학업·전공적합성·발전가능성·인성·탐구), 강점, 보완점, 추천 전공, 탐구활동 제안, 면접 예상 질문이 생성됩니다.
   - **🖨 리포트 PDF**로 저장/인쇄.
   - 같은 생기부를 **여러 번 분석**하면 종합 점수 **추이 그래프**가 나타납니다.

### 💡 수업 자료
1. `학습자료 생성` → 유형(퀴즈 문제지·빈칸채우기·개념 비교표·핵심 요약)·과목·학년·난이도·주제 입력.
2. **✨ AI로 생성하기** → 자료가 만들어지고 **내 자료함**에 저장됩니다.
3. `내 자료함`에서 유형·과목으로 필터링, 자료 열어 보기·**인쇄/PDF**.

### 📝 문서 작성
1. `문서 작성 → + 새 문서` → 제목 입력, 본문 작성(굵게·제목·목록 서식 지원).
2. `문서 템플릿`에 자주 쓰는 양식(가정통신문 등)을 저장 → 문서 작성 시 **‘템플릿 적용’**으로 불러오기.
3. **🖨 PDF 내보내기**로 완성 문서를 PDF로 저장.

### ⚙️ 시스템 관리
- **교사 관리 / 학급·반 관리 / 시간표 관리**: 추가·수정·삭제(표 형식).
- **계정·권한 관리**: 내 계정 정보와 역할 체계(교과교사·담임교사·보직교사·교무담당·관리자) 확인.
- **감사 로그**: 로그인·생성·수정·삭제·AI 사용 기록 추적.
- **시스템 현황**: 데이터 등록 현황을 통계·그래프로 확인.

## 4. 개인정보 · 안전

- 이름·연락처·주소·주민등록번호는 **AI 분석 전에 자동으로 가려집니다(마스킹)**.
- 입력 **원문은 서버 로그에 저장하지 않습니다.**
- 모든 주요 활동은 **감사 로그**에 기록됩니다.
- 그럼에도 **이름·연락처는 가급적 지우고** 입력하시길 권장합니다.
- AI가 생성한 내용은 **참고 자료**이며, **최종 검토·수정·책임은 교사**에게 있습니다(교육부 생성형 AI 활용 지침에 부합).

## 5. 자주 묻는 질문

**Q. 여러 학생을 관리할 수 있나요?**
A. 네. 학생별로 여러 개의 생기부와 분석 결과를 저장·관리할 수 있습니다.

**Q. 내가 만든 데이터는 다른 사람에게 보이나요?**
A. 본인 계정에 묶여 보관되며, 본인만 접근할 수 있습니다.

**Q. 합격 여부를 알려주나요?**
A. 합격/불합격을 단정하지 않습니다. 경쟁력 진단과 보완 방향, 탐구·면접 준비를 제안합니다.

**Q. 어떤 파일을 올릴 수 있나요?**
A. 생기부 입력 시 `.txt`, `.pdf` 파일에서 텍스트를 자동 추출합니다.

**Q. AI 분석이 안 돼요.**
A. 서비스에 AI 키가 설정되어 있어야 합니다(관리자 설정). 설정 후에는 바로 작동합니다.
