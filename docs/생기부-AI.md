# 생기부 AI — 제품 개요

## 한 줄 정의

학생이 생활기록부를 붙여넣으면, AI(입학사정관 페르소나)가 학생부종합전형 관점의
**진단 리포트**를 만들어 주는 웹 서비스. (참고: 생기부ON / vibeon.ai)

## 사용자 흐름

1. 학생이 생기부 텍스트를 붙여넣고(이름·연락처는 제거 권장), 선택적으로 희망 전공/학년 입력.
2. "분석하기" → 프론트가 `POST /api/analyze` 호출.
3. Worker가 개인정보 1차 마스킹 → Anthropic Claude 호출(강제 tool use, strict 스키마).
4. 구조화된 JSON 리포트를 받아 화면에 렌더.

## 리포트 구성

- 한 줄 총평 + 종합 경쟁력 점수
- 5개 평가영역 점수(학업역량/전공적합성/발전가능성/인성·공동체/탐구역량)
- 강점 / 보완점(실행 제안 포함)
- 추천 전공(적합도 + 근거)
- 생기부 항목별 분석(세특/창체/행특/독서 등)
- 후속 탐구활동 제안
- 예상 면접 질문(출제 의도 포함)

## 설계 원칙

- **사실성**: 생기부에 있는 근거로만 판단, 날조 금지.
- **개인정보 최소화**: 마스킹 + 프롬프트 무시 지시, 원문 로그 미기록.
- **건설적**: 합격/불합격 단정 대신 경쟁력 진단과 방향 제안.

## 향후 확장 아이디어

- PDF 업로드 → 텍스트 추출(현재는 붙여넣기)
- 항목별 점수 추이(학년별)
- 리포트 PDF 내보내기
- 교사용(작성 보조) 모드 — AI SchoolDesk 스타일 (별도 타깃)
