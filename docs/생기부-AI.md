# 생기부 관리 AI — 제품 개요

## 한 줄 정의

교사가 학생별로 생활기록부를 **관리**하고, AI(입학사정관 페르소나)가 학생부종합전형 관점의
**진단 리포트**를 만들어 저장해 주는 웹앱. (참고: AI SchoolDesk / 생기부ON)

## 사용자 흐름 (교사)

1. 회원가입/로그인 (이메일+비밀번호, 세션 쿠키)
2. **대시보드**: 학생 등록·목록 (이름/학년/희망전공)
3. **학생 페이지**: 그 학생의 생기부 목록 — 학기/버전별로 추가
4. **생기부 페이지**: 내용 편집·저장 → "AI 분석" → 리포트 생성·보관(다시 보기)

## 데이터 모델 (Cloudflare D1)

`users → students → records → analyses` (+ `sessions`).
모든 데이터는 로그인 계정(user)에 묶이고, API는 소유권을 검사한다.

## 리포트 구성

한 줄 총평 · 종합 경쟁력 점수 · 5개 평가영역 점수 · 강점/보완점 · 추천 전공 ·
항목별 분석 · 후속 탐구활동 · 예상 면접질문.

## 설계 원칙

- **사실성**: 생기부 근거로만 판단, 날조 금지.
- **개인정보 최소화**: 분석 전 마스킹 + 프롬프트 무시 지시, 원문 로그 미기록.
- **건설적**: 합격/불합격 단정 대신 진단·방향 제안.

## 향후 확장 아이디어

- 학생/생기부 검색·정렬, 태그
- 리포트 PDF 내보내기, 분석 이력 비교(버전 간)
- 생기부 작성 보조(세특 문장 생성) 모드
- 학교/반 단위 공유, 역할 권한

상세 도메인 지식·프롬프트·스키마는 `.claude/skills/saenggibu-analysis/` 참고.
