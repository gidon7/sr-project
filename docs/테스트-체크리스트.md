# 테스트 체크리스트 (회귀 점검)

배포 후 또는 기능 변경 후, 이 목록을 위에서 아래로 따라가며 확인합니다.
각 항목은 **동작 → 기대 결과** 형식입니다. 통과하면 `[x]` 로 체크하세요.

- 대상: **https://sr-project.pages.dev**
- 빠른 진입: 로그인 화면 또는 랜딩에서 **‘관리자 테스트 로그인’**

---

## 0. 사전
- [ ] 사이트가 열리고 흰 화면/콘솔 에러가 없다.
- [ ] (변경 후) 강력 새로고침(Ctrl+F5)로 최신 빌드를 받는다.

## 1. 인증
- [ ] **관리자 테스트 로그인** 클릭 → 대시보드(`/app`)로 이동.
- [ ] 새로고침해도 로그인 유지(쿠키 세션).
- [ ] 상단 우측 계정 → **로그아웃** → 랜딩으로 이동, 보호 페이지 접근 시 로그인으로 리다이렉트.
- [ ] 회원가입(이메일/8자+비밀번호) → 빈 계정으로 대시보드 진입.

## 2. 네비게이션 · UI (※ 이전에 버그 있던 부분)
- [ ] 사이드바 그룹 ▾ 클릭 → 펼침/접힘 동작.
- [ ] **수업 자료 → ‘학습자료 생성’ 클릭 시, ‘내 자료함’은 활성(파란색)으로 표시되지 않는다.** (역도 동일)
- [ ] 각 메뉴 클릭 시 **현재 메뉴만** 활성 표시된다.
- [ ] 학생 상세(`/app/students/:id`)에 있을 때 사이드바 ‘학생 관리’가 활성 유지된다.
- [ ] 좁은 화면(모바일)에서 ☰ 햄버거로 사이드바 열기/닫기.
- [ ] 어떤 페이지를 열어도 **흰 화면이 아니라** 정상 렌더(오류 시 빨간 오류 박스가 보임).

## 3. 대시보드
- [ ] 통계 카드(등록 학생/총 생기부/AI)와 모듈 카드가 보인다.
- [ ] ‘최근 학생’ 표의 행 클릭 → 해당 학생 페이지로 이동.

## 4. 생기부 분석
### 학생 관리
- [ ] `+ 새 학생 만들기` → 이름/학년/희망전공 입력 → 추가되면 표에 나타남.
- [ ] 학생 행 클릭 → 학생 상세로 이동.
- [ ] 🗑 삭제 → 확인 후 사라짐(행 클릭 이동과 충돌 없음).
- [ ] **CSV 내보내기** → `students.csv` 다운로드, 엑셀에서 한글 정상.
- [ ] **CSV 가져오기** → `이름,학년,희망전공` 형식 업로드 → 학생들이 추가됨.

### 생기부 작성/검사
- [ ] 학생에서 `+ 생기부 추가` → 제목 입력 → 편집 화면 진입.
- [ ] 본문 입력 시 **글자수·byte**가 실시간 갱신, 기준 초과 시 byte가 빨간색.
- [ ] 어학시험명/대학명 등 입력 시 **‘기재 주의 표현’** 칩이 표시된다.
- [ ] **📎 파일 불러오기** → `.txt` 업로드 → 본문에 텍스트가 채워짐.
- [ ] `.pdf` 업로드 → 텍스트 추출되어 채워짐(첫 PDF는 로딩에 잠깐 걸림).
- [ ] **저장** → ‘저장됨 시각’ 표시.

### AI 분석 (키 설정 시)
- [ ] **AI 분석** → 20~40초 후 리포트(종합점수·영역별·강점·보완점·추천전공·탐구·면접) 표시.
- [ ] 추천 전공이 생기부 활동과 **관련 있는** 분야로 나온다.
- [ ] **🖨 리포트 PDF** → 사이드바/편집기 제외, 리포트만 인쇄 미리보기.
- [ ] 같은 생기부를 **2회 이상** 분석 → ‘분석 점수 추이’ 그래프 표시.
- [ ] (키 미설정 시) “키를 등록하면 작동” 안내가 뜬다.

## 5. 수업 자료
- [ ] `학습자료 생성` → 유형/과목/학년/난이도/주제 입력 → **AI로 생성** → 자료 보기로 이동.
- [ ] `내 자료함`에 생성된 자료가 보이고, **유형/과목 필터**가 동작.
- [ ] 자료 행 클릭 → 내용(HTML) 표시, **🖨 인쇄/PDF** 동작.
- [ ] 🗑 삭제 동작.

## 6. 문서 작성
- [ ] `+ 새 문서` → 편집 화면. 굵게/제목/목록 서식 적용됨.
- [ ] `문서 템플릿`에서 템플릿 추가 → 문서 편집에서 **‘템플릿 적용’** 선택 시 내용 채워짐.
- [ ] **🖨 PDF 내보내기** 동작.
- [ ] 문서/템플릿 삭제 동작.

## 7. 시스템 관리
- [ ] **교사 관리**: 추가(이름 필수)/표시/삭제.
- [ ] **학급·반 관리**: 추가/표시/삭제.
- [ ] **시간표 관리**: 요일/교시 등 추가/표시/삭제.
- [ ] **계정·권한 관리**: 내 계정과 역할 표가 보인다.
- [ ] **감사 로그**: 방금 한 로그인/생성/삭제가 기록되어 있다.
- [ ] **시스템 현황**: 통계 카드 + 데이터 분포 막대그래프가 보인다(흰 화면 아님).
